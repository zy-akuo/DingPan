# 钉盘使用手册

面向最终用户与日常操作。若你收到的是 **zip 便携包**，解压后双击 **`一键安装启动.bat`** 即可。

---

## 一、安装与启动（发给别人的包）

### 1.1 系统要求

- Windows 10 或 11，**64 位**
- 能上网（访问东方财富 / 同花顺公开接口）
- WebView2（多数电脑已预装；缺则到微软官网安装 Edge WebView2 Runtime）
- **无需** 安装 Python、Node.js

### 1.2 步骤

1. 解压 `DingPan-portable.zip` 到任意文件夹  
2. 双击 **`一键安装启动.bat`**（也可用 `DingPan.bat`）  
3. 出现「钉盘」窗口；顶部「已连接」表示服务正常  
4. 关闭窗口即退出程序  

首次打开可能要几十秒～两分钟拉行情。非交易日可能显示最近交易日数据，或短暂为 0 后恢复。

### 1.3 用户数据位置

```
%APPDATA%\DingPan\
  ├── user_config.json   # 设置（列、语音、轮询秒数等）
  └── dingpan.db         # 历史与接口缓存
```

卸载：删除解压目录；可选再删上面文件夹。

### 1.4 包内文件

| 文件 | 说明 |
|------|------|
| `一键安装启动.bat` | **推荐入口**，启动桌面程序 |
| `DingPan.bat` | 同上 |
| `使用说明.txt` | 简短说明 |
| `docs\使用手册.md` | 本手册 |
| `resources\` | 内嵌 Python、后端、前端（勿删） |
| `Uninstall.bat` | 删除本目录（慎用） |

## 二、界面总览

1. **顶栏**：品牌、连接状态、更新时间、实时监控 / 连板天梯、设置  
2. **统计条**：涨停、连板、封板率、炸板、跌停（今日 vs 昨日）  
3. **主区**：监控表或天梯  

---

## 三、功能说明

### 3.1 实时监控

- **Tab**：涨停 / 连板 / 炸板 / 跌停  
- **筛选**：名称或代码模糊搜索；首封时间范围；成交额 / 自由流通 / 实际流通（单位：亿）；地域；可重置  
- **表格**：默认按首封从晚到早；点击行打开详情  
- **高亮**：从天梯跳转过来时会选中并滚动到该行  

### 3.2 连板天梯

- 按「几进几」分组，显示晋级率与成/败/炸  
- **点股票名**：分时 / 日线图（大弹窗，默认分时）  
- **点列表小图标**：跳到实时监控并选中该股、打开详情

### 3.3 详情与涨停雷达

抽屉内：基本面字段、涨停基因、价格轨迹、历史涨跌停明细。  
带本地缓存，同一股票第二次打开通常更快。

### 3.4 语音播报（设置）

- **实时播报**（默认关闭）：新涨停 / 连板晋级 / 炸板各播一次  
- 依赖 Windows 中文语音  

### 3.5 设置

| 项 | 说明 |
|------|------|
| 盘中轮询间隔 | 1～30 秒，默认 2.5；盘后自动降频 |
| 表格列 / 详情字段 | 勾选要显示的字段 |
| 语音 | 开关（默认关）、事件类型 |

保存写入 `%APPDATA%\DingPan\user_config.json`。

## 四、缓存与流畅性说明

- 服务端缓存：分时、日线、雷达、同花顺池等写入本地库，定时清理过期项  
- 前端缓存：详情/雷达/分时二次打开可先出缓存再刷新  
- 盘中行情推送频繁时，界面用过渡更新减轻卡顿  
- **功能未删减**；首次拉某只股票仍可能稍慢，属正常  

建议盘中轮询保持 2～5 秒；过小会加重网络请求。

## 五、日常建议

| 场景 | 建议 |
|------|------|
| 盘中盯盘 | 实时监控；需要时可开启实时语音；筛选栏缩小范围 |
| 看晋级 | 连板天梯；点名称看分时 |
| 复盘个股 | 详情雷达 + 近一年封板/连板率 |
| 盘后 / 周末 | 可看最近交易日；刷新较慢属正常 |

## 六、故障排查

| 现象 | 处理 |
|------|------|
| 双击无反应 / 闪退 | 确认解压完整；杀毒放行；勿只拷 bat 不拷 resources |
| 窗口空白 | 安装 WebView2 Runtime |
| 已连接全是 0 | 等 1～2 分钟；换网络；重启 |
| 端口失败 | 任务管理器结束旧钉盘/python；或设环境变量 `DINGPAN_PORT=17832` |
| 无语音 | 设置里开启；安装中文 TTS |
| 图表空白 | 关弹窗再开；稍后重试 |

自检：浏览器打开 `http://127.0.0.1:17831/api/health`，应返回 `ok: true`（程序运行中）。

## 七、开发者备注（源码模式）

若拷贝的是 **git 源码仓库** 而非便携 zip：根目录 `一键安装启动.bat` 会安装 Python/Node 并以**浏览器**模式启动开发服务。  
普通用户请使用 `packaging\out\DingPan-portable.zip`，不要发整个源码目录。

打包（仓库根目录双击即可）：

```bat
一键打包.bat
```

产物：`packaging\out\DingPan-portable.zip`。仅改后端时可加 `--skip-frontend`；要装机包可加 `--with-setup`。
